## What this project is

A computational, public-data, CPU-only causal-mediation project. Generated by anchoring idea
generation to the primary target PI, **Isidro Cortés-Ciriano** (EMBL-EBI; ERC *BrokenChromosomes* =
complex genomic rearrangements → immune evasion). Built on **his own published data** — the PCAWG
ShatterSeek chromothripsis calls (Cortés-Ciriano et al., *Nat Genet* 2020, PMID 32025003, supp.
Table S1). Distinct from Isha's other projects (ecdna-immune-mediation, etiology-cx, cin-ici-mediation).

## Final scientific status (do not re-chase without new data)

**Rigorously executed; honest negative. Not a positive flagship.**
- **A1 dissociation (TCGA):** WGD drives immune-cold (b=−0.339, p=6.6e-7, E=2.06), NOT the
  co-occurring chromothripsis (b=−0.144, p=0.038). Novel because they'd never been mutually adjusted.
- **A3 TMB:** dissociation sharpens (WGD −0.346, p=1.4e-6, E=2.08); chromothripsis loses significance
  (p=0.053). WGD tumours have MORE mutations yet are COLDER ⇒ not a neoantigen-deficit effect.
- **A2 two-channel mediation:** mediated by antigen presentation (28% [9,47]) NOT the cGAS-STING
  sensor (1% [−3,6], null). The original "sensor suppression = novel mechanism" hypothesis was
  **REFUTED**. APM only **confirms** Foidart 2026 (WGD→MHC-I silencing) — not novel.
- **A2b residual hunt:** ~71% direct/unexplained; no clean novel mediator (Treg/myeloid "mediators"
  are circular infiltration markers; stroma/TGF-β doesn't mediate WGD).
- **A5 replication: FAILS.** WGD effect collapses in independent non-TCGA ICGC/PCAWG RNA
  (−0.339 → −0.069, p=0.56); tumour-mix, lymphoid, data-quality and power all excluded. Effect is
  **cohort-dependent (likely TCGA-specific), not established biology.**
- **Honest publishable angle now = CAUTIONARY** (cohort-dependence of aneuploidy/WGD–immune
  associations), plus the reusable calcification label from the origin. NOT a positive mechanism paper.
